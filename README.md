# FOMO Control Center release transport

This repository is a transport-only surface for cryptographically bound release bytes.

- Deployment policy: owner-controlled devices only.
- These files are not a claim of Microsoft/public publisher trust.
- Private signing keys are never stored here.
- Source code remains in the private source repository.
- Release metadata binds exact source identity, package SHA-256, size, URL, and Ed25519 signature.
